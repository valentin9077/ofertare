# Ofertare lucrări instalații

Aplicație pentru generarea ofertelor de preț pentru lucrări de instalații
(sanitare, termice, pluviale, hidranți, PSI etc.).

## Ce face
- Catalog propriu de articole (manoperă) cu prețuri, organizate pe categorii.
- Construire ofertă din catalog: alegi articole, pui cantități, aplicația calculează totalurile și TVA.
- Recunoaștere produse cu denumiri diferite (ex: „brățară 1/2"" = „brățară 20 cu dublu și șurub").
- Export PDF: oferta sumar (pe categorii) + lista de cantități detaliată.
- Cont online cu sincronizare între telefon și laptop.

## Stadiu
În construcție, pas cu pas. Vezi folderul `exemple/` pentru materialele de referință
trimise de utilizator (oferte reale, liste de cantități, catalog de prețuri).
